🔥 Firebase Kurulum Rehberi
⚠️ Firebase yapılandırılmamış — Resimler ve müzikler sadece bu tarayıcıda görünüyor!
Firebase kurulursa: tüm resimler, müzikler, müşteriler bulutta saklanır ve her cihazdan erişilebilir.
Adım 1 — Firebase Projesi Oluştur
1. console.firebase.google.com adresine git
2. "Proje Ekle" → proje adı: beka-davet
3. Google Analytics'i devre dışı bırak → Proje Oluştur
Adım 2 — Web Uygulaması Ekle
1. Proje sayfasında "</> Web" ikonuna tıkla
2. Uygulama adı: beka-davet-web → Kaydet
3. Çıkan firebaseConfig değerlerini kopyala
Adım 3 — Firestore Database Aç
Sol menü → Firestore Database → Veritabanı oluştur
→ "Test modunda başlat" seç → Konum: europe-west1
Adım 4 — Storage Aç
Sol menü → Storage → Başlayın
→ "Test modunda başlat" → Aynı konum → Bitti
Adım 5 — admin.html'yi Güncelle
admin.html dosyasını metin editörüyle aç, en üstteki FIREBASE_CONFIG bölümünü bul ve değiştir:
const FIREBASE_CONFIG = {
  apiKey: "YOUR_API_KEY",
  authDomain: "YOUR_PROJECT.firebaseapp.com",
  projectId: "YOUR_PROJECT_ID",
  storageBucket: "YOUR_PROJECT.appspot.com",
  messagingSenderId: "123456789",
  appId: "1:123:web:abc123"
};
✅ Ücretsiz Limitler (Spark Plan)
📦 Storage: 1 GB (yüzlerce fotoğraf yeter)
📄 Firestore: 50.000 okuma / 20.000 yazma / gün
🌐 Hosting: 10 GB bant genişliği / ay
👤 Authentication: 10.000 kullanıcı / ay
